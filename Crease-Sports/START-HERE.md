# Crease Sports — Final Complete Project

## Run locally

Open this folder in VS Code and use Live Server on dist/index.html. No npm install or build is required. Alternatively, run:

    python -m http.server 5500 --directory dist

On Windows use py instead of python if needed, then open http://localhost:5500.

## Included

Two homepages, 48 products (12 per sport), About Us, Services with four detail pages, 16-brand directory, Team Orders, Contact Us, Privacy Policy and equipment guides. No login page or dashboard.

## Final fixes

The latest user folder and original media are preserved. The replacement cricket photo is used consistently. The generic Crease Selection brand is removed while all products remain. Hero frames and image fitting are corrected; the About orange outline is gone. Images/cards have hover feedback and entrance/reveal motion, with reduced-motion support. Home 2’s video uses its full 16:9 frame. Final adjustments are in dist/polish.css and dist/polish.js.

This is a frontend project. The kit bag and preferences stay in this browser. Contact and team forms generate downloadable drafts; they do not send messages, book services, take payments or place orders. Prices and store contact details remain illustrative. README.md contains further documentation and media sources.
